# APEX ARENA Client

Flutter application targeting Android, iOS, Web, Windows and macOS.

## Local setup
1. Install the Flutter stable SDK and platform toolchains.
2. From this directory run `flutter pub get`.
3. Run `flutter run -d chrome` for the web shell or select an installed device.
4. Do not add private API keys to source control. Use local ignored configuration and backend-issued media tokens.

The first client milestone is the Persian RTL application shell with system/light/dark theme selection. Audio/video integration is added only after backend room authorization is available.
